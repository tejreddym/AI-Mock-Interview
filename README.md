# AI Mock Interview Platform

A full-stack AI-powered mock interview application that helps users practice for job interviews with AI-generated questions, real-time evaluation, and detailed feedback.

## Features

### User Features
- 🔐 **User Authentication** - Secure login and registration
- 🎥 **Camera Preview** - See yourself during the interview
- ⏱️ **Timer** - Track interview duration in real-time
- 🤖 **AI-Generated Questions** - Customized questions based on job role and experience level
- 📝 **Text-based Q&A** - Type your answers at your own pace
- 🎯 **AI Evaluation** - Get scored (0-10) and detailed feedback on each answer
- 📊 **Progress Tracking** - View your interview history and improvement trends
- 📈 **Analytics Dashboard** - Track your performance over time

### Interview Types
- Technical interviews
- Behavioral interviews
- Mixed interviews

### Experience Levels
- Entry level
- Intermediate
- Senior

## Installation

### Prerequisites
- Node.js (v16 or higher)
- MongoDB (local or MongoDB Atlas)
- Google Gemini API key

### Backend Setup

1. Navigate to backend directory:
```bash
cd backend
```

2. Install dependencies:
```bash
npm install
```

3. Create `.env` file:
```bash
cp .env.example .env
```

4. Configure environment variables in `.env`:
```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/ai-mock-interview
JWT_SECRET=your-secret-key-here
GEMINI_API_KEY=your-gemini-api-key-here
NODE_ENV=development
FRONTEND_URL=http://localhost:5173
```

5. Start the backend server:
```bash
npm run dev
```

The backend will run on `http://localhost:5000`

### Frontend Setup

1. Navigate to frontend directory:
```bash
cd frontend
```

2. Install dependencies:
```bash
npm install
```

3. Create `.env` file:
```bash
cp .env.example .env
```

4. Configure environment variables in `.env`:
```env
VITE_API_URL=http://localhost:5000/api
```

5. Start the development server:
```bash
npm run dev
```

The frontend will run on `http://localhost:5173`

## Usage

1. **Register/Login**: Create an account or login to existing account
2. **Start Interview**: Click "Start New Interview" from dashboard
3. **Setup Interview**: 
   - Enter job role (e.g., "Software Engineer")
   - Select experience level
   - Choose interview type
   - Set number of questions (3-10)
4. **Take Interview**:
   - Questions are generated by AI
   - Camera preview shows your video feed
   - Timer tracks your progress
   - Type your answers
   - Get instant AI evaluation and feedback
5. **Review Results**: View detailed feedback and scores for each question
6. **Track Progress**: Monitor your improvement over time on the dashboard

## API Endpoints

### Authentication
- `POST /api/auth/register` - Register new user
- `POST /api/auth/login` - Login user
- `GET /api/auth/me` - Get current user

### Interviews
- `GET /api/interviews` - Get all user interviews
- `POST /api/interviews` - Create new interview
- `GET /api/interviews/:id` - Get specific interview
- `POST /api/interviews/:id/generate` - Generate questions
- `POST /api/interviews/:id/questions/:index/answer` - Submit answer
- `POST /api/interviews/:id/questions/:index/evaluate` - Evaluate answer
- `PUT /api/interviews/:id/complete` - Complete interview
- `GET /api/interviews/stats` - Get user statistics

## Deployment

### Frontend (Vercel)

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Set build settings:
   - Framework: Vite
   - Root Directory: `frontend`
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Add environment variable:
   - `VITE_API_URL`: Your backend URL

### Backend (Render)

1. Push your code to GitHub
2. Create a new Web Service on Render
3. Connect your repository
4. Set settings:
   - Root Directory: `backend`
   - Build Command: `npm install`
   - Start Command: `npm start`
5. Add environment variables:
   - `NODE_ENV`: production
   - `PORT`: 5000
   - `MONGODB_URI`: Your MongoDB connection string
   - `JWT_SECRET`: Your secret key
   - `GEMINI_API_KEY`: Your Gemini API key
   - `FRONTEND_URL`: Your frontend URL

### Database (MongoDB Atlas)

1. Create a free cluster on MongoDB Atlas
2. Create a database user
3. Whitelist IP addresses (0.0.0.0/0 for all)
4. Get your connection string
5. Update `MONGODB_URI` in your backend environment variables
